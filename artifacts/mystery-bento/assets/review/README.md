# Asset review queue

This folder contains preserved files that are not part of the current Mystery
Bento runtime. They remain available for art or narration review and should
not be imported by the app without first moving them back into the appropriate
source, derived, or runtime family.

## Unused candidates

- `unused/derived/contestants/cooking/` — aggregate cooking sheets and Toro
  frame exports superseded by the public cooking sprite sheets.
- `unused/audio/announcer/character-blurbs/` — 12 profile clips not selected by
  the current contest sequence.
- `unused/audio/announcer/contest-names/` — five title clips not selected by
  the current contest sequence.
- `unused/audio/announcer/unlabeled/` — one uploaded recording without a
  confirmed phrase label.

The `assets/archive/` folder is separate: it holds known superseded or alternate
material that is intentionally retained for provenance, such as the restaurant
alternates and the individual Pip frame exports.
